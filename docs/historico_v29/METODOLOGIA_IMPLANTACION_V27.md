
# Metodología de implantación V27

## Criterio central
En esta versión se adopta como referencia definitiva la imagen con rectángulos proporcionada por el usuario. Los rectángulos visibles en dicha imagen se consideran la representación geométrica base de las plazas.

## Aplicación
- No se reemplazan los rectángulos por marcadores genéricos.
- Se superponen capas rectangulares sobre la misma geometría para expresar el estado operativo.
- El color base del sector se conserva según el croquis original.
- El estado se comunica mediante relleno translúcido y realce visual.

## Resultado
El mapa maestro mantiene la coherencia visual con la referencia real suministrada y evita introducir iconografía que desvirtúe el croquis de implantación.
