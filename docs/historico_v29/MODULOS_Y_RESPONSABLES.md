# Módulos por actor

| Actor | Vista/Módulos principales |
|---|---|
| Administrador del sistema | Todos los módulos |
| Dirección de Grado | Panel, parqueos, ocupación, alertas, historial y reportes (consulta) |
| Jefe de Operaciones | Vehículos, acceso por placa, parqueos, ocupación, alertas, historial y reportes |
| Personal de Guardia | Vehículos (consulta), ingreso por cámara IA, validación excepcional, alertas e historial reciente |
| Soporte TIC | Panel técnico, usuarios/roles, dispositivos, alertas, auditoría, respaldos y configuración |
| Infraestructura | Zonas, plazas, cámaras de ocupación, mantenimiento, ocupación y alertas |
| Recursos Humanos | Vehículos, historial y reportes autorizados (consulta) |
| Estudiante | Únicamente `Mi parqueo`: Zona Estudiantes - Sector Trasero, espacios libres y mapa en tiempo real |
