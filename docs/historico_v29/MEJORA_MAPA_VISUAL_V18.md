
# PARKIA V18 · Mejora visual del mapeo

## Mejoras
- La imagen del campus dejó de ser solo referencial y ahora sirve como base visual del mapeo.
- Las plazas se muestran con bloques cuadrados directamente sobre la imagen.
- Cada bloque indica estado: disponible, ocupada, fuera de servicio o sin datos.
- Se mantienen las tres zonas institucionales: estudiantes, autoridades y administrativo.
- Se refuerza la lectura visual del módulo para una presentación más profesional.

## Nota
Las posiciones son una representación operativa alineada al croquis proporcionado por el usuario y pueden reajustarse si se realiza una medición de campo más precisa.
